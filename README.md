# ServiceNow Incident Lifecycle Automation

## 📌 Project Overview

This project demonstrates an Incident Lifecycle Automation system developed using ServiceNow.

The project focuses on managing incidents efficiently from creation to resolution by using ServiceNow features such as incident management, automation, workflows, and status management.

## 🎯 Objectives

- Create and manage incidents in ServiceNow
- Automate the incident lifecycle
- Track incident status and progress
- Improve incident resolution process
- Reduce manual effort through automation
- Provide better visibility of incident records

## 🛠️ Technologies Used

- ServiceNow
- Incident Management
- Flow Designer
- Business Rules
- UI Actions
- Tables and Forms
- Notifications
- GitHub

## ⚙️ Key Features

### 1. Incident Creation
Users can create incident records with relevant information such as:
- Short Description
- Description
- Caller
- Category
- Priority
- Assignment Group

### 2. Incident Lifecycle

The incident follows a structured lifecycle:

*New → In Progress → On Hold → Resolved → Closed*

### 3. Automation

ServiceNow automation is used to manage incident activities and reduce manual processing.

### 4. Status Management

Incident status can be updated according to the progress of the incident.

### 5. Resolution

Resolved incidents contain appropriate resolution information before being closed.
